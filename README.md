# Busyvine Bootstrap 5.3.8 Homepage

Responsive homepage template based on the approved Busyvine visual direction.

## Included
- Bootstrap 5.3.8 via official jsDelivr CDN
- Bootstrap Icons
- Responsive desktop/tablet/mobile layout
- Exact supplied Busyvine logo asset
- Busyvine primary cyan: `#00B2DD`
- Busyvine dark tone: `#19353A`
- Hero, trusted brands, work, services, belief, impact, insights, CTA and footer
- Sticky/translucent header on scroll

## Run locally
Open `index.html` directly, or serve the folder with any static server.

Example:
```bash
python3 -m http.server 8080
```
Then open `http://localhost:8080`.

## Notes
- The current photography uses remote Unsplash URLs as replaceable placeholders. Replace them with Busyvine-owned imagery before production.
- Google Sans is proprietary and is not distributed through Google Fonts. The CSS requests Google Sans if installed and falls back to Inter/system fonts. If you have licensed Google Sans webfont assets, add them locally with `@font-face`.
- Replace sample client names/project content with approved Busyvine case studies and verified metrics before launch.
